| 用户命名 | 眼型 | 嘴型 | 情绪 | **组合标签** |

**标签核实**：
- `xd` ❌ **不存在** → 用 `:d`（862.0k）替代
- `d:` → 词库写法是 **`:<`**（倒v嘴，55.3k）
- `happy` 141.9k ✅
- `crying` ✅
- `unhappy` ✅

> ⚠️ 用户写的 `xd` 在词库中不存在，改用 `:d`。

| 用户命名 | 眼型 | 嘴型 | 情绪 | **组合标签** |
|---|---|---|---|---|
| **调皮** | `>_o` | `:p` | happy | `>_o, :p, happy` |

## 九、与嘴部体系的配合

眼部与嘴部是两个独立维度，可自由组合：

```
[眼型] + [嘴型] + [情绪] + [辅助]
```

| 示例 | 标签串 |
|---|---|
| 大笑 | `>_<, :d, happy` |
| 调皮眨眼 | `one eye closed, :p, happy, tongue out` |
| 晕头转向 | `@ @, :o, confused, sweatdrop` |
| 无奈沉思 | `u_u, :\|, expressionless` |
| 阿黑颜 | `rolling eyes, empty eyes, :o, ahegao, tongue out` |
| 迷离 | `half-closed eyes, parted lips, blush` |

## 十一、工具限制

`tag-doctor.mjs` 已改为**直读词库索引**，颜文字标签可正常识别：

```bash
node bin/tag-doctor.mjs ">_<, @ @, u_u, >_o, one eye closed"
```

（旧版走 `rtag.mjs --search` 会因符号过滤而误报「未收录」）
