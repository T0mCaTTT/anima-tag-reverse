**情绪/符号标签核实**：
- `:o` 惊讶 267.3k ✅

> 用户写的 `^ ^` 对应 `^^^`（惊讶的，67.5k）；
> `@ @` 是晕眩眼，词库无直接对应，用 `flustered` 表达。

## 十、工具限制说明

`rtag.mjs --search ":d"` 会返回无结果 —— 这是**检索器的已知限制**（会过滤纯符号查询），
**不代表标签不存在**。核实颜文字标签请直接读词库：

```bash
node -e "
const j=JSON.parse(require('fs').readFileSync('search-index.json','utf8'));
const f=j.fields,iTag=f.indexOf('tag'),iZh=f.indexOf('zh'),iFreq=f.indexOf('freq');
console.log(j.rows.filter(r=>String(r[iTag])===':d').map(r=>[r[iTag],r[iZh],r[iFreq]]));
"
```

后续用 `tag-doctor.mjs` 体检时，颜文字标签可能被误报为"未收录"，需按本表人工确认。
