## 六、组合用法

腿部构图 = **体位** + **腿的位置** + **膝的位置**

| 画面 | 标签组合 |
|---|---|
| 仰躺屈膝（本图） | `on back, lying, knees up, legs up` |
| 仰躺双腿并拢屈起 | `on back, knees up, knees together feet apart` |
| 仰躺张开双腿 | `on back, spread legs, knees up` |
| 侧躺曲腿 | `on side, lying, knees up` |
| 抱膝坐 | `sitting, hugging own legs, knees to chest` |
| 跪坐开腿 | `wariza, kneeling` |
| 盘腿坐 | `sitting, indian style` |
| 二郎腿 | `sitting, crossed legs` |
| 双腿抬过头 | `legs over head, on back` |
| 单腿抬起 | `leg up, standing on one leg` |

## 七、看图定位流程

1. **体位**：躺 / 坐 / 跪 / 站 / 趴 → 从「基础体位」表选
2. **腿的位置**：张腿 / 抬腿 / 交叉 / 伸展 → 从「腿的位置」表选
3. **膝的位置**：屈膝 / 膝上 / 内八 → 从「膝的位置」表选
4. **脚的状态**：赤脚 / 脚底 / 脚趾 → 从「附属肢体」表选

**⚠️ 常见错误**：只写 `lying` 或 `sitting` 就完事 —— 腿部的具体姿态会完全丢失，
模型会自己乱猜。**腿的位置和膝的位置必须都写。**
