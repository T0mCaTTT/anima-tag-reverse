# 对白写法参考（dialogue-style：三档 + 通用）

> 定位一句话：**对白是让人物活起来的声音，不是剧情说明书。** 数字堆一堆没用，能落笔才作数——下面每一节都是可直接照做的规则、例子和红线。
>
> 来源：`adventyhwh/comfy-anima-skill-share` v4 的五份对白参考（`dialogue-style.md` 入口 + `dialogue-style-common.md` + `dialogue-style-safe.md` + `dialogue-style-sensitive.md` + `dialogue-style-nsfw.md`）合并成这一份；压字交付流程取自同仓库 v4 `anima-workflow/SKILL.md` §5。v4 本就没有独立的 explicit 篇（explicit 归 nsfw 篇），与技能的三档 **safe / sensitive / nsfw** 天然对齐，因此「档位 → 选篇」是一一映射，不需要第二张映射表。

## 0. 入口：按档只翻对应篇 + 通用篇

| 档位 | 本节 | 适用内容 |
|---|---|---|
| Safe | §2 Safe 篇 | 日常 / 热血 / 悲伤 / 压抑 |
| Sensitive | §3 Sensitive 篇 | 擦边 / 暧昧（过渡用，作品没这层就跳过） |
| NSFW | §4 NSFW 篇 | 色气 / 亲密 |
| 通用 | §1 通用篇 | 红线 / 符号 / 落笔流程 / 纪律（**每个档位都过一遍，很短**） |

- **写哪档读哪节 + 通用节；不写的那几节不翻开**——省上下文预算，也防止别的档位的腔调串进来。
- **按档位分批**：先把同档位页的对话框全部做完再切下一档，不按页码逐页写（防档位腔调串味）。
- 何时用：长篇成片**写对话框（压字）阶段激活**，每句对白逐句对照；短篇 / 单图台词同样适用。平时不读，写台词时再翻开。
- 语料来源：从多部商用 eroge 的明文事件脚本提取语料（RPG Maker / Unity / Godot Dialogic 等引擎格式），**只吸收结构和语感，不抄原文**。

技能侧的机读形态：显式传档位（`--rating <档名>`）时，面 3 `faces.dialogueSection` 会给出「本档该读哪节」；CLI 用 `--dialogue` 打印这份选篇，`--format json` 里对应键是 `dialogueSection`。不传档位 = 五个面整体关闭，这一节文档不会被自动挑出来。

## 1. 通用篇（三档都必过）

> 每个档位写之前都过一遍这一节，很短。具体招式在各档位篇里。

### 通用红线

- **旁白化对白**：对白在复述画面（「雨点打在我脸上」）→ 删，画面交给图
- **说明书对白**：一口气交代设定、身份、背景
- **全员一个腔调**：所有角色共用同一套省略号 + ～ + 语气词——每个角色要有自己的叹词 / 口头禅（口头禅是锚定声线最省力的办法）
- **日语直译语序**：不换结构直接搬日文句式
- **每句都是完整书面陈述**：零叹词、零停顿、零语气词

### 通用符号表

| 符号 | 意思 | 主要档位 |
|---|---|---|
| 「」 | 对白引号 | 全部 |
| ……（2 个点） | 犹豫 / 拖尾 | safe / sensitive |
| ………（3+ 个点） | 更长的沉默 | 压抑（safe） |
| ～ | 拖音 | safe 日常 |
| ♪ | 俏皮 / 好心情 | safe 日常 |
| ♡ ♥ | 爱意 / 沉溺 | sensitive / nsfw |
| 、 | 口吃 / 顿挫 | 全部 |
| ！？／！！／？？ | 情绪强度 | safe 热血 / nsfw |
| —— | 中断 / 被打断 | 全部（破折号 = 话被截断，省略号 = 自己说不下去） |
| （ ） | 内心小字 / 低语 | 全部 |
| `\c[n]` | 颜色标签 | 语料里 RPG Maker 脚本用，**写作时不写进对白** |

### 落笔流程（判据 + 自检）

1. 先定档位（safe / sensitive / nsfw），翻对应篇目选招。
2. 写完一句**读出声**：没有任何叹词 / 停顿 / 语气词、像书面语 → 板，重写。
3. 自检三问：这行删掉，画面信息有没有损失？→ 有损失就是旁白，不属于对白。这行除了交代信息，给了情绪吗？这句话换另一个人说，有区别吗？（声线）
4. 对白 ≠ 旁白：旁白走「短戳」规则（时间 / 地点锚、一句画外信息），不套活人气。

### 纪律

**对白永远用中文写。只吸收结构，不复制日语原文，不写日式语尾（ね / よ / な / だっ），不写翻译腔。** 参考是工具箱，写出来的是你自己的句子。

### 日文结构对应（照此转中文，勿抄日语）

口吃顿 `い、`＝`X、X`；叹词 `あ / え / う / わ` ＝ 哇 / 哎呀 / 诶 / 唔 / 呼；语尾 `ね / よ / な` ＝ 吧 / 呢 / 啦 / 哦 / 嘛。

## 2. Safe 篇（日常 / 热血 / 悲伤 / 压抑）

> 本节 = 无性内容对白。写这类读本节 + §1 通用篇。色气内容在 §3 / §4。

### 风格指引

**日常 / 轻松**（卖点：活泼、亲近、节奏快）

- 叹词开口：「哇——！」「诶，别卖关子了嘛……」
- 省略号做节奏：犹豫「……嗯。」／被断「那、那个……能借用一下厕所吗！？」
- 语尾语气词落地：吧 / 呢 / 啦 / 哦 / 嘛——「就这样再来一次吧♥」
- ～ 拖音 + ♪ 俏皮：情绪上扬时用，别每句都上
- 口吃顿 、：紧张 / 结巴「不、现在必须去上厕所……！」
- 拟态叠词：「毛茸茸毛茸茸～～！！」「软乎乎的好治愈～♪」

**热血 / 冒险**（卖点：气势、冲劲）

- 短句 + 叹词强收：「上吧——！」「别小看我啊——！！」
- 呼喊 / 命令式，句尾重音；少用省略号（犹豫会泄气）
- 报数 / 递进节奏：「一、二、三——上！」

**悲伤 / 感动**（卖点：克制）

- 省略号为主，句子短、停顿多，语尾轻放（……吧 / ……呢）
- 不说「我很难过」，说动作和感官：「……总觉得，这里的雨，好凉啊。」
- 重话轻说：越是重大的事，句子越短越平

**压抑 / 黑暗**（卖点：沉默）

- 陈述句冷收，语气词近零
- 「……」当重器；长句心理 + 短句重击交替
- 情绪用「没说出口的」表达，留白给读者

### 示例参考

- 「哇——！成功了成功了！！」
- 「诶，别卖关子了嘛……快说快说。」
- 「魔理沙～，你叉子呢，借我一下呗。」
- 「今、今天休业！都、都回去吧！！」
- 「轻轻松松就突破了1F呢♪」
- 「毛茸茸毛茸茸～～！！」
- 「别小看我啊——！！」
- 「……嗯，我知道了。」
- 「总觉得，这里的雨，好凉啊。」
- 「……」
- 「已经没有回去的必要了。」
- 「解除他们的苦痛的……义务……」

### 禁用于本档（词 + 风格）

- 情绪名词直说（「我很愤怒 / 悲伤」）→ 用动作、感官、断句代替
- 书面连接词（然而 / 于是 / 因此）进口语
- 翻译腔（「……的样子」「……的感觉」、被字句连发）
- 用力过猛：一句堆 >2 个语气词，或句句叹词 + ～
- 热血档用省略号拖尾（泄气）；悲伤 / 压抑档用叹词开场（跳戏）
- 本档不出现性描写词（器官 / 动作）——那是 §4 NSFW 篇的

## 3. Sensitive 篇（擦边 / 暧昧，过渡用）

> 介于 safe 与 nsfw 之间：脸红、欲言又止、贴近耳边的低语、没越线的亲密。作品里不出现这层就跳过本节。写本节也过一遍 §1 通用篇。

### 风格指引

- **欲言又止**：省略号把话咽回去「……你、你在看哪里啦！」
- **低语**：短句 + 音量感（小声 / 贴着耳朵），句尾轻
- **间接表达**：不直说心意，绕弯或交给动作：「要是……再靠近一点点的话……」
- **空间留白**：靠近、凑近、别贴这么近——用距离写张力
- **回避视线**：不正面接话，用转移「……我才没有在看你呢！」
- **气氛靠节奏不靠形容词**：心跳、气息、一阵沉默，用省略号隔开

### 示例参考

- 「……你、你在看哪里啦！」
- 「别、别靠这么近……会被人看见的……」
- 「要是……再靠近一点点的话……就……」
- 「嗯……没事的，我相信你……」
- 「刚才那个……不是故意要看的！」
- 「……我才没有在看你呢！」
- 「那个……我可以……握住你的手吗……？」

### 禁用于本档（词 + 风格）

- 不直露器官 / 动作词（那是 nsfw 的事，这档一露就破功）
- 不把擦边写成露骨；也不写成纯 safe 日常（那样没张力）
- 不用 ♡ 堆叠（那是 nsfw 的沉溺记号，这档最多轻用一次）

## 4. NSFW 篇（色气 / 亲密）

> 本节 = 露骨性内容对白。写这类读本节 + §1 通用篇。这档的招法是「呼吸感」，不是报动作。

### 风格指引

- **短促拟声 + 喘气**：嗯 / 呼 / 哼 / 呜 单字叠用，拟声词连发
- **♡ 作爱意 / 沉溺记号**：句尾「……♡」，密度随沉溺升高（平时少用，高潮才密）
- **省略号 + 破折号做气息断续**：一句话被呼吸切断
- **重复递进**：「喜欢…最喜欢了…♡」
- **语尾拖长 + 降调**：「嗯…♡」比「嗯！」更有沉迷感
- **不完整句 / 词序乱**：表现失控，语无伦次反而对
- **称呼变位**：动情时从「你」滑向名字 / 爱称（「……哥哥…」），关系感变化

### 示例参考

- 「啊……已经、这么…大、大了…！？」
- 「嗯啾♡ 啾噗♡ 哧噜哧噜♡ 嗯…♡」
- 「呼哦♡呜呜♡… 喔、哦哦♡♡」
- 「我喜欢…最喜欢了…♡」
- 「嗯♡……哈啊…♡ 再、再靠近一点…♡」
- 「那、那里……不行…♡」
- 「你已经……完全、是我的了…♡」
- 「……嗯♡ 就、就这样……别停…♡」

### 禁用于本档（词 + 风格）

- **报幕式流水账**：像 A 片导演旁白一样逐个报动作 → 对白是喘息和情绪，不是动作清单
- **整段只有喘息没有情绪**：缺「为什么」「属于谁」这类情感钩子就平
- **每句都 ♡ + 省略号**：密集到疲劳，读者会麻
- 器官名词整句连发（不是不能用，是不能当全部对白）
- 不写成说明书 / 教学式（先 xx 再 yy 然后 zz）

## 5. 长篇成片压字交付（压字阶段必读）

> 取自 v4 `anima-workflow/SKILL.md` §5。长篇出图 + 审计通过后，**交付物 = 压好对话框的成片，只交无字原图不算完成**。

### 台词文风：学漫画

- **对白** = 人物口语，怎么说话就怎么写（内心独白也是对白，用思考泡）。
- **旁白**只做画面做不到的事——时间 / 地点锚（「翌朝。」「台风夜。」）、画外信息一句带过；**不描述画面**，画面画了的东西再写一遍就是小说。判据：删掉这行旁白，画面信息没损失就删。
- 禁文艺腔与报告腔。
- **写对话框阶段激活本节所属的这份参考**：按作品档位只翻对应节——safe → §2、sensitive → §3、nsfw → §4，通用部分 §1 每个档位都要过（很短）。**不写的那几节不翻开**（省预算、防档位腔调串味）。**同档位页集中一批写完再切档。**
- 每句对白对照后落笔。**对白永远用中文，禁日式语尾（ね / よ / な / だっ）与翻译腔——参考只吸收结构不抄原文。**

### 三种件

- 对白 = **白气泡** + 尾巴指向说话人
- 内心独白 = **思考泡** + 圆点
- 旁白 = **米色框**

### 流程

1. 读图后**先按分镜表把每页标好档位**（safe / sensitive / nsfw）。
2. 然后**同档位页集中一批写台词 + 定坐标**（避脸避主体；激活该档位节 + 通用节，写完全档再切下一档，**不按页码 1、2、3、4 逐页写**——防档位腔调串味），存 `captions_<书>.md`。
3. 压完**抽查 3 页**。
4. 压字用自写脚本（bake_bubble 思路：台词 + 坐标表驱动；换行、防超宽、行尾孤字 + 行头标点禁则已内置——实测长句会在行首掉出逗号，**禁则必须两条都有**）。

### 产出

- 日期文件夹根层 = 成片（`P01_标题.png`）；
- `_raw/` = 无字原图；
- `_reject/` = 废案（带原因命名，重 roll 旧版逐张移入，别只数数量）；
- output 根目录不留散图。
