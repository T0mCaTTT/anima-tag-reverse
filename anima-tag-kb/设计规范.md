## 3. 毛玻璃配方

统一一条：`--glass-blur: blur(22px) saturate(1.7)`，配合半透明表面 + 1px 描边 + 顶部内高光。

| 组件 | 表面（夜间） | 表面（日间） | 描边 | 内高光 | 阴影 |
|---|---|---|---|---|---|
| 页头 `header` | `rgba(13,16,26,.72)` | `rgba(255,255,255,.70)` | `--glass-brd` | `inset 0 1px 0 rgba(255,255,255,.07)` | `0 8px 28px rgba(0,0,0,.16)` |
| 底部托盘 `#tray` | `linear-gradient(180deg,玻璃,玻璃-2)` | 同 | 同 | 同 | `0 -14px 40px rgba(0,0,0,.32)` |
| 装配台 `.drawer` | `rgba(13,16,26,.72)` | `rgba(255,255,255,.70)` | 同 | 同 | `--sh-2` |
| 悬浮检视窗 `#insp` | `rgba(13,16,26,.72)` | 同 | 同 | 同 | `--sh` |
| 复制浮标 `#toast` | `rgba(11,13,20,.86)` | `rgba(255,255,255,.90)` | 同 | 同 | `--sh-1` |

- 标签卡**不使用**毛玻璃（保持实底），避免文字被身后内容干扰。
- 兜底：`@supports not ((backdrop-filter:blur(2px)) or (-webkit-backdrop-filter:blur(2px)))` → 上述五个表面改回 `var(--bg2)` 不透明底。
- 日志/标签串输出框 `--code-bg`（夜间 `#0a0c14` / 日间 `#f1f3f9`）不用玻璃，保证等宽文本清晰。

## 4. 圆角尺度

| 令牌 | 值 | 用在哪 |
|---|---|---|
| `--r1` | `10px` | 卡片右上角小按钮、角标 |
| `--r2` | `12px` | 所有 `button` / `input` / `select` |
| `--r3` | `14px` | 次级面板、抽屉内块 |
| `--r4` | `16px` | 面板、手机端托盘顶部圆角 |
| `--r5` | `18px` | 标签卡、页头、托盘、悬浮窗、抽屉（`--r` = `--r5`） |
| `--pill` | `999px` | 分类条 / 小分类条 / 已选 chip / 徽章 / 主题按钮 |

规则：**同层级同半径**；嵌套时子元素 = 父元素 − 4px（如 18 卡片内 14 内块）；任何可点元素不得使用直角（`border-radius:0` 仅出现在手机端全宽抽屉的四角与工具按钮的贴边侧）。

## 5. 动效规范

| 令牌 | 值 | 语义 |
|---|---|---|
| `--dur-1` | `150ms` | 微交互：hover、按下、徽章淡入 |
| `--dur-2` | `260ms` | 面板级：抽屉滑入、悬浮窗淡入、托盘展开 |
| `--dur-3` | `420ms` | 主题切换圆形扩散 |
| `--ease` | `cubic-bezier(.4,0,.2,1)` | 标准（进出对称） |
| `--ease-out` | `cubic-bezier(.22,.8,.28,1)` | 柔和出场 |
| `--ease-spring` | `cubic-bezier(.34,1.4,.64,1)` | 回弹（月亮进场、卡片点选） |

具体动作：

| 交互 | 属性 | 时长 / 曲线 |
|---|---|---|
| 卡片悬停 | `translateY(-3px)` + 边框转 `--chip-brd` + 阴影加深 | 150ms / `--ease` |
| 卡片按下 | `scale(.985)` | 90ms / `--ease` |
| 卡片点选 | `.cbtn2` 收藏星与已选勾淡入 + 浮标 `#toast` 上浮淡出 950ms | 150ms / `--ease` |
| 分类条切换 | 活动 chip 底色/描边渐变，内容区交叉淡入 | 150ms + 260ms |
| 抽屉 | `transform: translateX(100%) → 0` | 260ms / `--ease-out` |
| 悬浮窗 | `opacity + translateY(6px)` | 150ms / `--ease` |
| 主题切换 | View Transitions 圆形扩散（`clipPath: circle(0 → R)`，圆心 = 按钮中心） | 420ms / `--ease` |
| 主题图标 | 太阳（旋转 -35°→0）与月亮（旋转 35°→0）交叉淡入缩放 | 420ms / `--ease-spring` |

降级链：
1. 浏览器支持 `document.startViewTransition` → 圆形扩散揭幕；
2. 不支持 → `html.theme-switching` 挂 480ms 全局过渡，做整页交叉淡入；
3. `prefers-reduced-motion: reduce` → 所有 `transition/animation` 时长归零，主题瞬时切换。

## 6. 组件规格

### 6.1 页头（sticky，2 行，三段式）
- 第一行 `.hrow.htop` 分三段（对齐参考仓库 ai-tag-toolbox 的 header 三段式）：`.hleft`（品牌「Anima 标签工作台」17px/700 前置 8px `--ac` 圆点 + `☰` 分类栏开关 34×34）、`.hmid`（搜索框 `min(440px,40vw)` + 搜索模式下拉 + 分组下拉，`flex:1` 居中，是页头唯一"工作区"）、`.hright`（36×36 主题按钮 + 缩略图开关 + 使用说明 + ★收藏夹（带 `#favn` 计数徽章）+ 装配台主按钮，`margin-left:auto` 右对齐）。
- 第二行 `.hrow.hstats`：统计行（`--tx3` 12px，顶部 1px `--line` 分隔，≤980px 隐藏）。
- 分类导航不再占用页头（原第 2、3 条分类条已移除）：一级入口移到左侧竖栏 `aside.rail`（§6.2），当前所在层级由主区工具条 `.toolbar` 显示（§6.9）。
- 页头整体：`backdrop-filter` 毛玻璃、`--head-sh`、底部 1px `--line`；`padding:10px 18px 8px`。

### 6.2 左侧分类栏 `.rail` 与行式分类按钮 `.cbtn`
- 容器 `aside.rail`：`width:var(--rail-w)`，默认 `clamp(200px,16vw,240px)`（≤1180px 196px）；`position:sticky`，`top:var(--rail-top)`（由脚本把页头实高 +1px 写入），`max-height:calc(100vh - var(--rail-top) - 14px)`，纵向滚动；右侧 1px `--line` 分隔；顶部 `.railhead` 放分区标签「分类」（12px `--tx3`）+ 窄条开关 `.railmini-btn`（20×20，窄条态旋转 180°）。
- 行式按钮 `.cbtn`（固定 26 行 = ★收藏 / 全部分类 / 24 个一级分组）：`display:flex;width:100%;gap:9px;border-left:3px solid transparent`；活动态左色条变 `--ac` + `--chip-bg` 底（借鉴参考仓库 `.cat.on{border-left-color}`）。

- **三态**（宽屏）：`展开` ⇄ `窄条`（`.shell.railmini`，66px 只剩图标与活动色条；`.cname` 淡出、`.n` 隐藏、`.railgrip` 隐藏）⇄ `完全隐藏`（`.shell.railoff`，`display:none`，主区占满）。单击 `☰` 或 `Ctrl/Cmd+Shift+B` 在「完整 ⇄ 窄条」间切换，**Shift+点击 ☰** 才完全隐藏（再按一次恢复）；状态记 `localStorage('animaKB.rail')` = `on` / `mini` / `off`。
- **宽度可拖拽**：`.railgrip`（`position:absolute;left:var(--rail-w);width:11px;transform:translateX(-5px);cursor:col-resize;z-index:6;touch-action:none`）是拖拽把手，静止透明，`:hover` / `:focus-visible` / 拖拽中（`.shell.railresizing`）显示 2px `--ac` 竖线；拖拽中给 `.rail` 关 `transition` 防迟滞。取值 `RAIL_W_MIN = 168px`、`RAIL_W_MAX = 380px`，且不超过视口 34%（`Math.round(innerWidth * 0.34)`）；双击把手复位为 CSS 默认，把手聚焦后 `←` / `→` 每次 ±16px；宽度记 `localStorage('animaKB.railW')`（无值 = 用 CSS 默认）。动画：`.rail{transition:width var(--dur-2) var(--ease),padding var(--dur-2) var(--ease)}` + `.cname/.n/.clabel{transition:opacity var(--dur-1) var(--ease)}`。

### 8.4 主题切换（圆形扩散揭幕 + 降级）

```js
const THEME_KEY = 'animaKB.theme';
const themeNow = () => document.documentElement.dataset.theme === 'light' ? 'light' : 'dark';
function commitTheme(t){
  document.documentElement.setAttribute('data-theme', t);
  try{ localStorage.setItem(THEME_KEY, JSON.stringify(t)); }catch(e){}
  const m = document.querySelector('#metaTheme');
  if (m) m.setAttribute('content', t === 'light' ? '#f5f6fa' : '#0b0d14');
}
function setTheme(t, ev){
  if (t === themeNow()) return;
  const reduce = matchMedia('(prefers-reduced-motion: reduce)').matches;
  if (!document.startViewTransition || reduce){          // 降级：整页过渡
    document.documentElement.classList.add('theme-switching');
    commitTheme(t);
    setTimeout(()=>document.documentElement.classList.remove('theme-switching'), 480);
    return;
  }
  const btn = document.querySelector('#btnTheme');
  const r = btn ? btn.getBoundingClientRect() : { left:innerWidth/2, top:0, width:0, height:0 };
  const x = ev && ev.clientX ? ev.clientX : r.left + r.width/2;
  const y = ev && ev.clientY ? ev.clientY : r.top + r.height/2;
  const R = Math.hypot(Math.max(x, innerWidth-x), Math.max(y, innerHeight-y));
  const tr = document.startViewTransition(()=>commitTheme(t));
  tr.ready.then(()=>{
    document.documentElement.animate(
      { clipPath:[`circle(0px at ${x}px ${y}px)`, `circle(${R}px at ${x}px ${y}px)`] },
      { duration:420, easing:'cubic-bezier(.4,0,.2,1)', pseudoElement:'::view-transition-new(root)' }
    );
  });
}
```

## 9. Lottie 动画规范

- 画布 48×48，30fps，60 帧（0–30 日→夜，30–60 反向），矢量纯色，无位图依赖。
- 图层：`sun-rays`（8 角星，帧 0–18 旋转 150° + 缩到 20% + 淡出）→ `sun-core`（圆，缩到 55% 淡出）→ `moon`（圆 + 两个陨石坑，帧 12–26 回弹放大进场、42–50 淡出）→ `sparkle`（四角星，帧 18–32 闪烁）。

- 页面内**未**引入 Lottie 播放器（离线优先），而是用同参数的 20×20 内联 SVG + CSS 过渡实现；Lottie 文件用于 Figma / AE / LottieFiles / 其他播放器。
- 重新生成：`node scripts/make-theme-lottie.mjs`。
- 预览：`assets/lottie-preview.html`（左 CDN 播放器、右无依赖 CSS 版）；已实测 SVG 渲染 6 条路径（光芒 / 太阳核心 / 月面 + 2 个陨石坑 / 星光）。
